# 畅课助手 · AstrBot 插件

> 为 AstrBot 开发的畅课（TronClass）助手插件 —— **作业不再错过，点名不再迟到**。

对接中国传媒大学畅课系统（`courses.cuc.edu.cn`），支持**微信扫码一键登录**、**作业查询与截止提醒**、**课表驱动的点名实时通知**，多用户独立绑定、互不干扰。

## ✨ 功能特性

| | 能力 | 说明 |
|---|------|------|
| 🔐 | **微信扫码登录** | 无需密码和验证码，扫码即可绑定账号；也支持账号密码 + 短信二次认证（CAS SSO） |
| 📋 | **作业查询** | `/作业列表` 查看未完成作业，按截止时间排序，支持离线缓存 |
| 🔔 | **作业提醒** | 定时检测新作业发布、快到期作业，私聊自动推送 |
| 🏫 | **点名通知** | 上传 .ics 课表后仅在上课时检测点名，扫码/数字签到码实时推送 |
| 👥 | **多用户** | 每位成员独立绑定畅课账号，会话隔离、互不干扰 |
| 🛡️ | **Session 自动管理** | 登录过期自动检测并提醒重新登录；凭据加密存储 |

## 🚀 快速开始

### 安装

将插件克隆到 AstrBot 的插件目录：

```bash
cd data/plugins
git clone https://github.com/wiikaros/astrbot_plugin_tronclass.git
```

重启 AstrBot 或在 WebUI 插件管理中加载。依赖（`aiohttp` / `icalendar` / `pycryptodome` / `cryptography`）会在加载时自动安装。

### 首次使用（三步上手）

1. **登录**：在**私聊**中发送 `/微信登录`，扫码确认即可
2. **导入课表**（推荐）：发送 `/上传课表`，将教务系统导出的 `.ics` 课表文件发给机器人
3. **查看作业**：发送 `/作业列表` 或 `/更新作业`

> 没有微信？账号密码登录：`/登录畅课`（私聊，含短信二次认证）。

## 📋 命令一览

| 命令 | 功能 | 适用场景 |
|------|------|---------|
| `/微信登录` | 微信扫码登录 | 私聊 |
| `/登录畅课` | 账号密码登录（多轮交互） | 私聊 |
| `/作业列表` | 查询未完成作业（本地缓存） | 群聊/私聊 |
| `/更新作业` | 手动刷新作业列表 | 群聊/私聊 |
| `/上传课表` | 上传 .ics 课表文件 | 私聊/群聊（带文件） |
| `/重置登录限制` | 清除登录频率限制 | 管理员 |
| `/调试作业` | 打印缓存原始作业数据 | 管理员 |

## ⚙️ 配置

在 AstrBot WebUI 的**插件管理 → 畅课助手 → 配置面板**中调整：

| 配置项 | 默认值 | 说明 |
|--------|--------|------|
| 服务器地址 | `courses.cuc.edu.cn` | 畅课服务器地址 |
| 作业检测间隔 | 30 分钟 | 自动检测作业更新的频率 |
| 点名检测间隔 | 5 分钟 | 无课表时的点名检测频率 |
| 课前提前检测 | 5 分钟 | 上课前多久开始检测点名 |
| 快到期提醒 | 24 小时 | 距截止多久时提醒 |
| 新作业通知 / 快到期提醒 / 点名通知 | 开启 | 三类通知的独立开关 |

## 🔔 自动通知

- **作业检测**：默认每 30 分钟检测一次新作业与快到期作业
- **点名检测**：有课表时仅在上课时间段内检测；无课表时按默认间隔轮询
- **过期提醒**：Session 失效时私聊通知重新登录

> ⚠️ **平台兼容性**：定时主动推送依赖 IM 平台的主动消息 API，目前仅以下平台支持：
> **Telegram、OneBot v11（NapCat/Lagrange 等）、Slack、飞书、Discord、Misskey、Satori**。
> 其他平台（如 QQ 官方 API、微信）无法主动推送，请用 `/更新作业` 手动刷新。

## ⚠️ 使用须知

- **登录期间命令会被暂拦**：密码登录进行中，该用户的其他命令会被拦截（提示"登录流程进行中"），发送 **「退出」** 可取消
- **登录频率限制**：每用户每小时最多尝试 3 次登录，超限需管理员 `/重置登录限制` 或等待 1 小时
- **凭据安全**：登录凭据经加密后存储，密码与短信验证码不落盘、不入日志
